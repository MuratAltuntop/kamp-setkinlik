# Kampüs Etkinlik

Canlı adres: _(Vercel linki buraya eklenecek: https://isimsoyisim-frontend.vercel.app)_

## Kurulum

```bash
cd frontend
npm install
npm run dev
```

## Route listesi

| Adres | Sayfa |
| --- | --- |
| `/` | HomePage |
| `/events` | EventsPage |
| `/events/:id` | EventDetailPage |
| `/login` | LoginPage |
| `/register` | RegisterPage |
| `/forgot-password` | ForgotPasswordPage |
| `/admin` | AdminPage |
| `/admin/new` | AddEventPage |
| `/admin/:id/edit` | EditEventPage |
| `*` | NotFoundPage |
